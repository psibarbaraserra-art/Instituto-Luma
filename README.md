# Instituto Luma · Gestão
App administrativo do Instituto Luma – Luz para mães atípicas: mães, atendimentos, Círculo de Cuidado, voluntários, estagiários, financeiro, patrimônio, documentos e prazos, relatórios em PDF.

Os dados ficam só no aparelho. Faça a cópia de segurança todo mês em Configurações.
Para mudar obrigações e documentos, edite `obrigacoes.js`.
